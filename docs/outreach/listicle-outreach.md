# Listicle Outreach — "Best AI Gateway / LLM Router 2026"

Google'da "best AI gateway 2026", "best LLM router 2026", "OpenRouter alternatives" gibi arandığında ilk sayfada çıkan yazıların çoğu 2024-2025 dönemi. Bu yazarların 2026 refresh'inde Unichanl'ı listeye eklemesi için proaktif outreach gerekiyor. Bu doküman, o outreach'i sistematik yürütmek için template + hedef site listesi.

## Ana strateji

- Hedef: 10+ blogger'a e-posta, %30 response rate, %10 listing sonucu (yani 1-2 gerçek liste ekleme).
- Her mail: kişiye özel açılış + kısa neden + press kit link + tek CTA.
- Follow-up: 7 gün sonra 1, 21 gün sonra 1 daha. Toplam 3 dokunuş.
- Asla money offer yapma — bu tarz publisher'lar ilk dokunuşta "sponsored slot" isterse ayrı bir konuşma, ama outreach'te para teklif etme.
