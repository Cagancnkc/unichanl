One API for Multiple AI Models

Güncelleme: 16 Eylül 2026 · 8 dk okuma
TL;DR: Unichanl tek bir gateway key ile Anthropic Claude, OpenAI GPT, Google Gemini, AWS Bedrock ve Google Vertex modellerine hem OpenAI-uyumlu /v1/chat/completions hem de Anthropic-uyumlu /v1/messages endpoint'lerinden erişim sağlar. Kod tarafında sadece model alanını değiştirerek provider değiştirirsiniz; anahtar yönetimi, failover ve fatura tek yerden akar.

Sorun: her provider için ayrı entegrasyon

Modern bir AI uygulaması tipik olarak birden fazla model kullanır: karmaşık planlama için Claude Opus, hızlı yanıt için Haiku, vision için GPT-4o, uzun context için Gemini 2.5 Pro. Bu her provider için:

  • Ayrı SDK
  • Ayrı API anahtarı
  • Ayrı fatura
  • Ayrı rate limit yönetimi
  • Ayrı hata yönetimi

Bir gateway katmanı bunları tek çatı altında birleştirir.

Python: tek SDK, tüm modeller

from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:20128/v1",
    api_key="sk-unichanl-YOUR_KEY"
)

# Aynı SDK ile Claude
r1 = client.chat.completions.create(
    model="claude-sonnet-4",
    messages=[{"role":"user","content":"Refactor önerisi"}]
)

# Aynı SDK ile GPT
r2 = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role":"user","content":"Refactor önerisi"}]
)

# Aynı SDK ile Gemini
r3 = client.chat.completions.create(

TypeScript / Node

import OpenAI from "openai";

const ai = new OpenAI({
  baseURL: "http://127.0.0.1:20128/v1",
  apiKey: process.env.UNICHANL_KEY
});

const models = ["claude-sonnet-4", "gpt-4o", "gemini-2.5-pro"];
for (const model of models) {
  const r = await ai.chat.completions.create({
    model,
    messages: [{ role: "user", content: "Test" }]
  });
  console.log(model, r.choices[0].message.content);
}

Kullanım senaryosu: multi-model uygulama

Bir SaaS uygulaması müşteri desteği + kod üretimi + görsel analiz özellikleri sunuyor. Kod tarafında tek bir ai.chat() fonksiyonu var; parametre olarak task_type alıyor. Router seçim mantığı:

const modelMap = {
  support: "claude-haiku-4",   // hızlı ve ucuz
  code:    "claude-sonnet-4",  // kaliteli refactor
  vision:  "gpt-4o",           // görsel analiz
  long:    "gemini-2.5-pro"    // 1M+ context
};

async function ai(taskType, prompt) {
  return client.chat.completions.create({
    model: modelMap[taskType],
    messages: [{ role: "user", content: prompt }]
  });
}

Ay sonunda fatura tek TL cinsinden gelir, muhasebe için tek e-arşiv fatura.

Faydalar özet

  1. Tek SDK / tek anahtar / tek fatura.
  2. Model değişikliği sadece string değişikliği — kod değişikliği yok.
  3. Cross-provider failover (Anthropic direkt → Bedrock → Vertex).
  4. Kullanım metrikleri (token, latency, cost) tek dashboard'da.
  5. KVKK aydınlatma metni + Türkiye e-arşiv fatura.

Sınırlamalar

  • Her modelin özel parametreleri (Anthropic'in thinking, OpenAI'nin response_format) yalnızca ilgili provider'da çalışır. Router bu farkları normalize etmeye çalışır ama edge case'lerde farkındalık gerekir.
  • Streaming her iki format için de destekli, ancak SSE frame yapısı endpoint'e göre değişir.
