Cursor Entegrasyonu

Güncelleme: 16 Eylül 2026 · 5 dk okuma
TL;DR: Cursor'ı Unichanl gateway'e bağlamak için Settings → Models altında OpenAI Base URL'i http://127.0.0.1:20128/v1 ve API Key'i Unichanl gateway key'inizle değiştirin. Aynı ekranda Anthropic Base URL'i http://127.0.0.1:20128 yapın. Tek anahtar ile Chat, Composer, Cmd+K ve Tab özelliklerinin tamamı yerel gateway üzerinden failover'lu çalışır.

Ön gereksinimler

  • Cursor 0.42+ (Custom API mode desteği için).
  • Unichanl gateway kurulu ve 127.0.0.1:20128'de dinliyor.
  • Aktif gateway key (5$ minimum topup).

Adım 1: Gateway'i başlat

npm install -g unichanl
unichanl start --key sk-unichanl-YOUR_KEY

# Sağlık kontrolü:
curl http://127.0.0.1:20128/health
# {"status":"ok","upstreams":3,"routing":"failover"}

Adım 2: Cursor Settings

Cmd/Ctrl + , → Models → OpenAI API Key bölümünü açın.

OpenAI ayarları

API Key            : sk-unichanl-YOUR_KEY
Override OpenAI URL: http://127.0.0.1:20128/v1
Verify             : [Verify butonuna basın → yeşil "Verified" görünmeli]

Anthropic ayarları

Anthropic API Key: sk-unichanl-YOUR_KEY
Anthropic URL    : http://127.0.0.1:20128

Adım 3: Model listesi

Cursor'un model dropdown'unda:

  • claude-sonnet-4 — günlük kodlama
  • claude-opus-4 — büyük refactor
  • claude-haiku-4 — Tab autocomplete
  • gpt-4o — vision / diagram
  • gemini-2.5-pro — çok uzun context

Adım 4: Test

Yeni bir dosyada Cmd+K açın, "// print hello world" yazın. Yanıt anında gelmeli. Unichanl loglarında istek görünecek:

[unichanl] POST /v1/chat/completions model=claude-sonnet-4
[unichanl] upstream=anthropic-direct latency=142ms tokens_out=18

Team modu için sub-key kullanımı

5+ kişilik ekipler için ana gateway key'i doğrudan paylaşmak yerine dashboard'dan kişi bazlı sub-key üretin. Her sub-key:

  • Kendi kullanım limitine sahiptir (aylık 20$ gibi).
  • Kişi bazlı dashboard'da görünür.
  • Çalışan ayrılınca iptal edilebilir; ana key değişmez.
unichanl subkey create --name "developer-ali" --monthly-cap 25
# → sk-unichanl-sub-abc123...

Somut senaryo

10 kişilik bir React ekibi Cursor'da Composer ile büyük bir migration üzerinde çalışıyor. Her geliştiriciye sub-key veriliyor. Aylık 250$ bütçe belirlendi. Cursor'un kendi "usage-based" fiyatı yerine Unichanl marjsız Sonnet 4 fiyatıyla harcama %8-10 azaldı; ayrıca ekip TL'li KDV'li fatura aldı.

Cursor Rules ile model önerisi

.cursorrules dosyanıza şu ipucunu koyun:

# .cursorrules
- Composer/Chat için varsayılan model: claude-sonnet-4
- Uzun dokümantasyon üretimi için: gemini-2.5-pro
- Görsel/diagram için: gpt-4o

Sorun giderme

"Failed to verify" hatası

Gateway ayakta mı? Base URL'in sonunda /v1 var mı? curl -v http://127.0.0.1:20128/v1/models ile doğrulayın.

Chat çalışıyor ama Composer takılıyor

Composer büyük context gönderir; timeout'u artırın veya claude-sonnet-4 yerine gemini-2.5-pro deneyin (1M+ context).

Tab autocomplete gecikmeli

Tab için ayrı model belirtin: Cursor Settings → "Tab Model" → claude-haiku-4.
