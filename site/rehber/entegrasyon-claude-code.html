Claude Code Entegrasyonu

Güncelleme: 16 Eylül 2026 · 6 dk okuma
TL;DR: Claude Code CLI'yi Unichanl gateway ile kullanmak için iki env değişkeni yeterlidir: ANTHROPIC_BASE_URL=http://127.0.0.1:20128 ve ANTHROPIC_API_KEY=sk-unichanl-.... Gateway ayakta olduğu sürece Claude Code, Anthropic direkt, Bedrock ve Vertex arasında otomatik failover yapar. macOS/Linux için ~/.zshrc, Windows için PowerShell environment variable kullanın.

1. Unichanl gateway kurulumu

npm install -g unichanl
unichanl start --key sk-unichanl-YOUR_KEY

2. Env değişkenleri

macOS / Linux (zsh)

cat >> ~/.zshrc <<'EOF'
export ANTHROPIC_BASE_URL="http://127.0.0.1:20128"
export ANTHROPIC_API_KEY="sk-unichanl-YOUR_KEY"
EOF
source ~/.zshrc

macOS / Linux (bash)

cat >> ~/.bashrc <<'EOF'
export ANTHROPIC_BASE_URL="http://127.0.0.1:20128"
export ANTHROPIC_API_KEY="sk-unichanl-YOUR_KEY"
EOF
source ~/.bashrc

Windows PowerShell (kalıcı)

[Environment]::SetEnvironmentVariable(
  "ANTHROPIC_BASE_URL", "http://127.0.0.1:20128", "User")
[Environment]::SetEnvironmentVariable(
  "ANTHROPIC_API_KEY", "sk-unichanl-YOUR_KEY", "User")

# Yeni bir PowerShell açın, doğrulayın:
$env:ANTHROPIC_BASE_URL

3. Doğrulama

claude "hangi model üzerinden konuşuyorum ve base url ne?"
# Cevabı beklerken başka bir terminalde:
unichanl logs --follow

4. Arka plan servisi

macOS / Linux (pm2)

npm install -g pm2
pm2 start "unichanl start --key sk-unichanl-YOUR_KEY" --name unichanl
pm2 save
pm2 startup   # Sistem başlangıcında otomatik çalışır

Linux (systemd)

# /etc/systemd/system/unichanl.service
[Unit]
Description=Unichanl AI Gateway
After=network.target

[Service]
Type=simple
User=your_user
ExecStart=/usr/bin/unichanl start --key sk-unichanl-YOUR_KEY
Restart=always

[Install]
WantedBy=multi-user.target
sudo systemctl enable --now unichanl

Windows (NSSM)

nssm install unichanl "C:\Program Files\nodejs\node.exe" "C:\...\unichanl\bin\unichanl.js" start --key sk-unichanl-YOUR_KEY
nssm start unichanl

5. MCP server'lar ile birlikte kullanım

Claude Code'un MCP server'ları gateway'den bağımsız çalışır — MCP stdio üzerinden Claude Code process'iyle konuşur, network trafiği gateway'e girmez. Yani hem MCP hem gateway aynı anda sorunsuz çalışır.

6. Model seçimi

Claude Code varsayılan olarak claude-sonnet-4'ü kullanır. Değiştirmek için:

claude --model claude-opus-4 "büyük refactor önerisi ver"
claude --model claude-haiku-4 "hızlı özet"

7. Somut kullanım senaryosu

Bir freelancer haftada 40 saat Claude Code kullanıyor. Direkt Anthropic key'i ile Tier-2 limit'i haftada 2-3 kez aşıyor ve session'ları kesiliyor. Unichanl'a geçince:

  • 3 farklı Anthropic anahtar dashboard'a eklendi → round-robin havuz.
  • Bedrock upstream backup olarak eklendi.
  • 4 haftadır tek bir kesinti yok.
  • Aylık fatura TL cinsinden, KDV'li e-arşiv fatura.

8. Sorun giderme

"ECONNREFUSED 127.0.0.1:20128"

Gateway ayakta değil. unichanl status ile kontrol edin.

"401 Invalid API Key"

Anthropic key'i (sk-ant-...) yerine Unichanl gateway key'i (sk-unichanl-...) kullanmalısınız.

Bazı istekler yavaş

Bir upstream (ör. Bedrock) yavaş yanıt veriyor olabilir. Dashboard'da per-upstream latency'yi görün, sıralamayı düzenleyin.

Env değişkenleri yüklenmiyor

Yeni terminal penceresi açın veya source ~/.zshrc çalıştırın. Windows'ta ise yeni PowerShell/CMD açın.
