Claude Code Rate Limit Çözümü: Yerel Gateway ile

Güncelleme: 12 Eylül 2026 · 8 dk okuma
TL;DR: Claude Code rate limit hatası (429 Too Many Requests) alıyorsanız, Unichanl yerel gateway'i kurup 2+ Anthropic API anahtarını havuzlayabilirsiniz. Biri takılırsa gateway otomatik diğerine döner. 5 dakikalık kurulum, sorun çözülür.

Sorun tanısı: 429 hatası nedir?

Claude API'nin kendi başına rate limit'i vardır: Per-minute token limiti, request limiti. Yoğun kullanımda (özellikle büyük prompt'lar, sık çağrılar) limiti aşabilirsiniz.

Error: 429 Too Many Requests
message: "Rate limit exceeded. Please retry after 60 seconds."

Bu sorun ile karşılaştığınızda Claude Code kendisini 60+ saniye suspend eder. Kod yazamızsınız; verimsiz.

Çözüm 1: Anahtarları havuzlama (Unichanl)

Anthropic API'ye birden fazla anahtar oluşturun. Unichanl bu anahtarları havuzlar — istek rate-limit'e takılırsa gateway otomatik diğer anahtarını kullanır.

Adım 1: Anthropic anahtarlarını oluştur

console.anthropic.com/keys'e git.
Create Key butonuna tıkla 3-5 anahtar oluştur. Her anahtarı not et.

Adım 2: Unichanl'ı kur

npm install -g unichanl
unichanl start

Adım 3: Dashboard açılır — anahtarları ekle

Tarayıcı otomatik http://127.0.0.1:20128 açılır.
Settings → Provider Keys'e git.
Adım 1'deki 3-5 Anthropic anahtarını ekle.
Kaydet.

Adım 4: Claude Code'u yapılandır

Claude Code ayarları açın. .env veya config'e ekle: 

ANTHROPIC_BASE_URL=http://127.0.0.1:20128
ANTHROPIC_API_KEY=unichanl-gateway-key (dashboard'dan kopyala)

Adım 5: Test et

Claude Code'da büyük bir prompt gönder. Şu şekilde çalışacaktır:
• İstek 1 → Anahtar 1 rate-limit yok → başarı
• İstek 2 → Anahtar 1 rate-limit'e girdi → gateway Anahtar 2'ye döner → başarı
• İstek 3 → Anahtar 2 rate-limit'e girdi → gateway Anahtar 3'e döner → başarı

Çözüm 2: Ek bakiye yükle

Basit çözüm: daha fazla bakiye yükleyin. Ama rate-limit (RPM, TPM) ortaya çıkabileceği için kalıcı değil.

Çözüm 3: Provider failover

Unichanl'da OpenAI, Google Vertex, AWS Bedrock da upstream olarak ekleyebilirsiniz. Anthropic rate limit'e girerse, Unichanl istekleri OpenAI'ye yönlendirir. Maliyeti artar ama kodlama kesintiye uğramaz.

Sık sorulan sorular

Kaç anahtar havuzlamalıyım?

3 minimum, 5-10 ideal. Her anahtar bağımsız rate-limit'e sahiptir; toplanır.

Ücret artacak mı?

Hayır. Aynı token sayısını havuzla yönetmekle, tek anahtardan göndermeyin arasında fark yoktur. Havuzlama bedavadır.

Otomatik failover ne kadar hızlı?

Milisaniye cinsinden. Hiç hissedilmez; kullanıcı için sorunsuz.

Tüm Anthropic modellerine mi uygulanır?

Evet. Sonnet, Opus, Haiku tüm modellerde rate-limit ortaya çıkabilir ve Unichanl tüm modellere uygulanır.
