Gemini CLI Entegrasyonu

Güncelleme: 16 Eylül 2026 · 5 dk okuma
TL;DR: Google Gemini CLI'yi Unichanl gateway ile kullanmak için OpenAI-uyumlu modda çalıştırın ve OPENAI_BASE_URL=http://127.0.0.1:20128/v1 ile OPENAI_API_KEY=sk-unichanl-... set edin. Unichanl gemini-2.5-pro ve gemini-2.5-flash modellerini Google AI Studio veya Vertex AI upstream üzerinden servis eder; kota bittiğinde otomatik olarak diğer upstream'e döner.

1. Gateway kurulumu

npm install -g unichanl
unichanl start --key sk-unichanl-YOUR_KEY

2. Gemini CLI OpenAI-compat mode

Gemini CLI yakın zamanda OpenAI-uyumlu endpoint desteği ekledi. Bu modda base URL değişikliği yeterlidir:

gemini --openai-compat \
  --base-url http://127.0.0.1:20128/v1 \
  --api-key sk-unichanl-YOUR_KEY \
  --model gemini-2.5-pro \
  "src/router.ts dosyasındaki failover mantığını gözden geçir"

3. Kalıcı env değişkenleri

# macOS / Linux
export OPENAI_BASE_URL="http://127.0.0.1:20128/v1"
export OPENAI_API_KEY="sk-unichanl-YOUR_KEY"
export GEMINI_MODEL="gemini-2.5-pro"
# Windows PowerShell
[Environment]::SetEnvironmentVariable("OPENAI_BASE_URL", "http://127.0.0.1:20128/v1", "User")
[Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-unichanl-YOUR_KEY", "User")

4. Native Gemini API modu

Bazı Gemini CLI kullanımları native Google API'yi bekler. Unichanl bu format için proxy modu sunar:

export GOOGLE_API_BASE="http://127.0.0.1:20128/google"
export GOOGLE_API_KEY="sk-unichanl-YOUR_KEY"

gemini "1M token'lık PDF'i özetle"

6. Somut senaryo

Bir teknik yazar, 3.000 sayfalık ürün dokümantasyonundan changelog üretmek için Gemini 2.5 Pro'nun 1M+ context'ini kullanıyor. Direkt Google AI Studio'da free tier limit'i günde birkaç kez doluyor ve iş duruyordu. Unichanl gateway ile:

  • Primary upstream: Google AI Studio (paid).
  • Backup upstream: Vertex AI (europe-west4 bölgesi).
  • Kota bittiğinde otomatik Vertex'e düşüş.
  • Aylık harcama TL cinsinden tek fatura.

7. Cross-model routing örneği

Unichanl aynı gateway üzerinden Gemini ile Claude arasında geçişi tek komutla mümkün kılar:

# Uzun context için Gemini
gemini --model gemini-2.5-pro "docs/ klasörünü özetle"

# Kod refactor için Claude (aynı base URL)
codex --model claude-sonnet-4 "src/auth.ts'yi test edilebilir hale getir"

8. Sorun giderme

"Model not found: gemini-2.5-pro"

Gateway upstream olarak Google AI Studio veya Vertex bağlı değil. Dashboard'da provider ekleyin.

"429 quota exceeded"

Tek upstream'de Google kota limit'i doldu. Dashboard'a ikinci bir Google project ekleyip round-robin açın veya Vertex'i backup olarak set edin.

PDF/multimodal isteklerde hata

Multimodal içerik için native Google API modu (/google path) tercih edin; OpenAI-compat mode her multimodal feature'ı desteklemeyebilir.
