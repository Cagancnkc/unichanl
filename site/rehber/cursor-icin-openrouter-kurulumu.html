Cursor için OpenRouter Kurulumu: Adım Adım

Güncelleme: 12 Eylül 2026 · 6 dk okuma
TL;DR: Cursor Settings → Models sekmesinde OpenRouter seç, API anahtarını gir. 300+ model erişim. Kurulum 2 dakika.

Adım 1: OpenRouter hesabı oluştur

openrouter.ai'ye git.

Sign Up → Email + parola ile hesap aç (veya Google, GitHub oAuth).

Settings → API Keys'e git.

Create Key tıkla, API anahtarını kopyala. Bunu not et (birazdan gerekecek).

Minimum 5$ yükle (kredi kartı veya bank transferi).

Adım 2: Cursor'ı aç ve Settings'e git

Cursor IDE'yi aç.

Cmd+K (Mac) veya Ctrl+K (Windows/Linux) → settings yaz → Settings aç.

Models sekmesini bulun.

Adım 3: OpenRouter'ı provider olarak seç

Provider açılır menüsünde OpenRouter seç.

API Key alanına Adım 1'den kopyaladığın anahtarı yapıştır.

Save / Apply tıkla.

Adım 4: Model seç

Model sekmesinde 300+ modellerden seç:

  • anthropic/claude-3.5-sonnet (önerilir, hız ve kalite dengesi)
  • openai/gpt-4o (güçlü ama pahalı)
  • google/gemini-2.0-flash (hızlı, ucuz)
  • anthropic/claude-3-opus (güçsü ama çok pahalı)
  • deepseek/deepseek-r1 (ucuz, reasoning)

Başlangıçta Sonnet veya o1-mini tavsiye edilir.

Adım 5: Test et

Cursor'da yeni bir dosya oluştur.

Chat açılır menüde OpenRouter'ın seçili olduğunu doğrula.

Kodlama isteği gönder: Python'da fibonacci fonksiyonu yazılı

Eğer model cevap verirse başarılı demektir!

Fiyatlandırma tamamı

OpenRouter ~%5 marj ekler provider fiyatına:

  • Sonnet 3.5: ~$3/1M input tokens, ~$15/1M output tokens
  • o1-mini: ~$3/1M input, ~$12/1M output
  • Gemini 2.0 Flash: ~$0.075/1M input, ~$0.3/1M output

100 istekte ortalama 30K token → ~0.5$ maliyet.

İpuçları

  • Model değiştirmek istersen: Settings → Model → yeni model seç. Anında geçiş.
  • Rate limit alırsan: İsteğin başında söyle: "Bekle, rate limit'e girdiysem farklı model dene" — OpenRouter otomatik fallback'e gitmez; sen manuel yapmalısın.
  • Masraf takip: OpenRouter dashboard'ında Usage sekmesinde aylık masrafı gör.
  • Unichanl alternatifi: OpenRouter yerine Unichanl local gateway'i kullansan, marj ve latency azalır.
