Codex CLI Entegrasyonu

Güncelleme: 16 Eylül 2026 · 5 dk okuma
TL;DR: OpenAI Codex CLI'yi Unichanl gateway ile kullanmak için OPENAI_BASE_URL=http://127.0.0.1:20128/v1 ve OPENAI_API_KEY=sk-unichanl-... env değişkenlerini ayarlayın. Codex CLI, tüm OpenAI-uyumlu isteklerini yerel gateway'e gönderir; Unichanl bunları OpenAI direkt, Azure OpenAI veya alternatif provider arasında failover ile yönlendirir. Marj yok, KVKK uyumlu, 5$ minimum topup.

1. Gateway kurulumu

npm install -g unichanl
unichanl start --key sk-unichanl-YOUR_KEY

2. Codex CLI env değişkenleri

macOS / Linux

export OPENAI_BASE_URL="http://127.0.0.1:20128/v1"
export OPENAI_API_KEY="sk-unichanl-YOUR_KEY"

# Codex bazı sürümlerde ayrıca:
export OPENAI_API_BASE="http://127.0.0.1:20128/v1"

Windows PowerShell

[Environment]::SetEnvironmentVariable("OPENAI_BASE_URL", "http://127.0.0.1:20128/v1", "User")
[Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-unichanl-YOUR_KEY", "User")

3. Doğrulama

codex --version
codex "readme.md dosyasını özetle"
# Aynı anda:
unichanl logs --follow

4. Model seçimi

Codex CLI varsayılan olarak gpt-4o veya kullandığı sürüme göre o1 kullanır. Model değişikliği için:

codex --model gpt-4.1 "test dosyası üret"
codex --model o1 "algoritmanın karmaşıklığını çıkar"

Unichanl aynı endpoint'ten Claude modellerini de servis eder — kod tarafında sadece model adı değişir:

codex --model claude-sonnet-4 "TypeScript'e refactor et"

5. Somut senaryo

Bir DevOps ekibi CI/CD pipeline'larında Codex CLI'yi kullanıyor: her PR'de otomatik test üretimi, migration script'i oluşturma, docstring güncelleme. Direkt OpenAI key'iyle Tier-3 limit sık sık PR queue'yu bloke ediyordu. Unichanl'a geçtikten sonra:

  • 2 OpenAI + 1 Azure OpenAI anahtar havuzlandı.
  • CI pipeline'ları hiç failover'sız çalışıyor.
  • Aylık ~%7 tasarruf (marj yok).
  • KVKK gereksinimleri karşılandı.

6. CI kullanımı (GitHub Actions örneği)

name: Codex Review
on: [pull_request]
jobs:
  review:
    runs-on: self-hosted   # Unichanl gateway kurulu runner
    env:
      OPENAI_BASE_URL: http://127.0.0.1:20128/v1
      OPENAI_API_KEY: ${{ secrets.UNICHANL_KEY }}
    steps:
      - uses: actions/checkout@v4
      - run: npm install -g codex-cli
      - run: codex review --pr ${{ github.event.number }}

7. Sub-key ile bütçe kontrolü

unichanl subkey create --name "ci-codex-runner" --monthly-cap 50 --scope openai-only
# → CI için ayrı, aylık 50$ limitli anahtar

8. Sorun giderme

"401 Unauthorized"

OpenAI key (sk-...) yerine Unichanl key (sk-unichanl-...) kullanılmalı.

Codex hâlâ direkt OpenAI'a gidiyor

Bazı Codex CLI sürümleri OPENAI_API_BASE değişkenini kullanır; ikisini birden set edin.

Streaming yanıtlar takılıyor

Gateway varsayılan olarak SSE'yi destekler. Corporate proxy arkasındaysanız NO_PROXY=127.0.0.1 set edin.
