Cursor AI Gateway: Unichanl Entegrasyonu

Güncelleme: 16 Eylül 2026 · 6 dk okuma
TL;DR: Cursor'da Settings → Models altında "Override OpenAI Base URL" alanına http://127.0.0.1:20128/v1 ve API key olarak Unichanl gateway key'inizi girin. Cursor'un tüm AI istekleri (Cmd+K, Chat, Composer, Tab) yerel gateway üzerinden geçer; Anthropic ve OpenAI arasında otomatik failover yapılır. KVKK uyumlu, marj yok, 5$ minimum.

Cursor'da neden gateway kullanılır?

Cursor, kendi cloud proxy'si üzerinden OpenAI/Anthropic'e konuşur ve "usage-based pricing" ile fatura keser. Kendi API anahtarlarınızı Custom API mode'da kullanmak isterseniz üç sorunla karşılaşırsınız:

  1. Rate limit havuzlaması yok — tek anahtar takılırsa Cursor'un Composer'ı durur.
  2. Failover yok — Anthropic outage sırasında iş durur.
  3. Türkiye'den KVKK / VAT uyumu ayrı bir süreç.

Unichanl bu üç problemi tek gateway ile çözer.

Adım 1: Unichanl gateway'i başlat

npm install -g unichanl
unichanl start --key sk-unichanl-YOUR_KEY
# 127.0.0.1:20128 aktif

Adım 2: Cursor ayarlarını aç

Cmd/Ctrl + , ile Settings'i açın → Models sekmesi.

Adım 3: OpenAI Override

"OpenAI API Key" alanına Unichanl gateway key'inizi girin:

API Key: sk-unichanl-YOUR_KEY
Override OpenAI Base URL: http://127.0.0.1:20128/v1
Verify: (Cursor "Verified" göstermeli)

Adım 4: Anthropic Override

Aynı ekranda Anthropic bölümüne:

Anthropic API Key: sk-unichanl-YOUR_KEY
Base URL: http://127.0.0.1:20128

Adım 5: Model seçimi

Model listesinden claude-sonnet-4, claude-opus-4, gpt-4o veya gpt-4.1 seçin. Unichanl her modeli uygun provider'a yönlendirir.

Doğrulama testi

# Terminalde
curl http://127.0.0.1:20128/v1/chat/completions \
  -H "Authorization: Bearer sk-unichanl-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4",
    "messages": [{"role":"user","content":"ping"}],
    "max_tokens": 50
  }'

Yanıt 200 döndüyse Cursor'da Cmd+K açıp "hello" yazın. Unichanl loglarında istek görünmeli.

Somut senaryo: Frontend refactor haftası

Bir hafta boyunca 5 kişilik bir ekip Cursor Composer ile büyük bir Next.js refactor'u yapıyor. Anthropic Tier-2 limitleri günün ortasında dolmaya başlıyor. Unichanl'ın round-robin router'ı sayesinde 3 farklı Anthropic anahtar, 1 Bedrock ve 1 Vertex upstream'i arasında yük dağılıyor — Composer hiç durmuyor. Hafta sonunda dashboard'da harcama TL cinsinden görünüyor, muhasebe için tek fatura kesiliyor.

Cursor Tab (Copilot mode)

Tab autocomplete küçük ve hızlı bir model kullanır. Unichanl'ın cost routing modunu açıp Tab isteklerini claude-haiku-4'e yönlendirebilirsiniz. Composer istekleri otomatik olarak Sonnet/Opus'a düşer.

Team modu için ipuçları

  • Ekip üyelerine tek gateway key dağıtmak yerine dashboard'dan kişi bazlı sub-key üretin.
  • Aylık bütçe alarmı kurun — 80% seviyesinde e-posta uyarısı.
  • Fatura için Türkiye'de KDV'li e-arşiv fatura seçeneği aktif.

Sorun giderme

Cursor "Failed to verify"

Gateway ayakta mı? curl http://127.0.0.1:20128/health ile kontrol edin.

Composer takılıyor

Base URL'in sonunda /v1 olduğundan emin olun (OpenAI için). Anthropic için /v1 olmamalı.

Tab autocomplete yavaş

Latency routing'i açın veya Tab modelini Haiku'ya sabitleyin. Localhost gecikmesi 1-2ms, Anthropic'e giden hop 40-80ms olmalı.
