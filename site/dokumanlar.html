Kurulum. 60 saniye.

Unichanl, tek bir tkg_* anahtarıyla Claude, GPT ve Gemini modellerine erişmeni sağlayan yerel bir AI gateway'idir. Aşağıdaki adımlar tüm CLI'lar için ortaktır; sonra editörüne özel bloğu kopyala.

1. Kurulum 2. API anahtarı Claude Code Cursor Codex Gemini CLI OpenCode

1. Unichanl binary'sini kur

Tek satırlık kurulum. 127.0.0.1:20128 üzerinde yerel gateway başlatır. Prompt içerikleri diskte kalmaz, yalnızca metadata loglanır.

# macOS / Linux
curl -fsSL https://unichanl.com/install.sh | sh

# Windows (PowerShell)
iwr https://unichanl.com/install.ps1 -useb | iex

# Başlat
unichanl start

2. API anahtarı oluştur

Dashboard → API anahtarları → Yeni anahtar. Anahtar tkg_ ile başlar ve yalnızca bir kez gösterilir.

export UNICHANL_API_KEY="tkg_..."
export UNICHANL_URL="http://127.0.0.1:20128"
Anahtarı git veya paylaşılan config'e commit'leme. Kaybedersen dashboard'dan iptal edip yenisini üretebilirsin.

Claude Code

~/.claude/settings.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:20128/v1",
    "ANTHROPIC_API_KEY": "tkg_..."
  }
}

Cursor

Settings → Models → Custom OpenAI Endpoint
Base URL:  http://127.0.0.1:20128/v1
API Key:   tkg_...
Model:     claude-sonnet-4-6

OpenAI Codex CLI

~/.codex/config.toml
[provider]
base_url = "http://127.0.0.1:20128/v1"
api_key  = "tkg_..."
model    = "gpt-5"

Gemini CLI

~/.gemini/config.json
{
  "apiEndpoint": "http://127.0.0.1:20128/v1beta",
  "apiKey": "tkg_...",
  "model": "gemini-2.5-pro"
}

OpenCode
