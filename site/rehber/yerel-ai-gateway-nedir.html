Yerel AI Gateway Nedir? 2026 Teknik Rehberi

Güncelleme: 12 Eylül 2026 · 10 dk okuma
TL;DR: Yerel AI gateway, bilgisayarınızda çalışan bir ağ ara sunucusudur. Kodlama araçlarınız (IDE, CLI) gateway'e istek gönderir; gateway bunları Anthropic, OpenAI, Google gibi upstream provider'lara yönlendirir. İstekler doğrudan bilgisayarınızdan çıkar; cloud ara atlaması yoktur. Faydası: failover, rate limit havuzlama, KVKK gizliliği, kesintisiz çalışma.

Temel kavram: Proxy vs Gateway

Proxy (OpenRouter, Helicone)

Cloud ortasında bir sunucu. Tüm istekler orada geçer. Üretim gözlemi için idealdir; ancak ekstra hop, marj ve privacy endişesi vardır.

Claude Code → Internet → OpenRouter (US) → Anthropic → Internet → Claude Code

Gateway (Unichanl, LiteLLM)

Bilgisayarınızda koşan bir sunucu. İstekler doğrudan oradan upstream'e gider. Privacy, latency ve kontrol için idealdir.

Claude Code → Localhost:20128 (Unichanl) → Anthropic → Localhost:20128 → Claude Code

Yerel Gateway Mimarisi

Katmanlar:

  1. Client layer: Claude Code, Cursor, Codex CLI, SDK. ANTHROPIC_BASE_URL=http://127.0.0.1:20128'e istek gönderir.
  2. Gateway layer: Unichanl daemon. Localhost:20128'de dinler. İstek alır, yönlendirir, yanıt döner.
  3. Upstream layer: Anthropic, OpenAI, Google, Bedrock, Vertex. Gerçek modelleri çalıştırır.

Failover Mantığı:

Upstream 1 (Anthropic) aşağı düşerse veya rate limit'e girerse, gateway Upstream 2'ye (OpenAI) döner. Client hiç farkında değildir; istek hiç düşmez.

Neden developer'lar gateway kullanır?

1. Rate limit havuzlaması

Birden fazla API anahtarının limitlerini birleştirirsiniz. Biri takılırsa, diğeri devam eder.

2. Provider failover

Anthropic aşağı düşerse, Unichanl istekleri Bedrock/Vertex'e yönlendirir. Kodlama seansı kesilmez.

3. Gizlilik

İstekler doğrudan bilgisayarınızdan çıkar. Cloud proxy'de değildir. Türkiye'de KVKK uyumu sağlanır.

4. Marj yok

Gateway yalnızca yönlendirir. Cloud proxy'ler ~%5 marj ekler; gateway bunu atlatır.

5. Latency

Localhost iletişimi internet üzerinden US'a gitmekten hızlıdır (~1ms vs ~200ms).

Sık sorulan sorular

Gateway açık kalması mı gerekir?

Evet. Gateway açık olmadığı sürece IDE istek gönderemez. Ancak bir kez başlatıldıktan sonra arka planda çalışır.

Güvenlik riski mi var?

Hayır. Gateway yalnızca upstream'e istek yönlendirir. Şifre, token gibi hassas bilgiyi saklamaz. Metadata logluyor, prompt/response içeriğini değil.

En iyi seçim hangisi?

OpenRouter: model çeşitliliği istiyorsanız. Unichanl: Claude Code'u kesintisiz çalıştırmak istiyorsanız. LiteLLM: kurumsal kontrol istiyorsanız. Portkey: üretim observability istiyorsanız.
