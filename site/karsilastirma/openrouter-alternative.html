OpenRouter Alternative: Unichanl Yerel AI Gateway

Güncelleme: 16 Eylül 2026 · 7 dk okuma
TL;DR: OpenRouter'a alternatif arayan geliştiriciler için Unichanl, bilgisayarınızda 127.0.0.1:20128 üzerinde çalışan yerel bir AI gateway'dir. Model üzerine %5 marj eklemez, KVKK uyumludur, birden fazla API anahtarını havuzlar ve rate limit'e girdiğinizde otomatik failover yapar. 5$ minimum topup ile başlar, Claude Code/Cursor/Codex/Gemini CLI ile tek anahtardan çalışır.

Neden OpenRouter alternatifi arıyorsunuz?

OpenRouter geniş bir model kataloğu sunar ama üç yaygın sorun geliştiricileri alternatif aramaya iter:

  1. %5 marj: Her istekte modelin gerçek fiyatının üzerine ~%5 eklenir. Aylık 200$+ harcamada bu fark somutlaşır.
  2. Cloud hop gecikmesi: Tüm istekler ABD'deki OpenRouter sunucularından geçer. Türkiye'den ~200ms ek gecikme.
  3. KVKK / veri egemenliği: OpenRouter US TOS altında çalışır; kurumsal kullanımda hukuki soru işaretleri.

Hızlı kurulum (2 dakika)

Unichanl npm ile kurulur ve tek komutla ayağa kalkar:

npm install -g unichanl
unichanl start --key sk-unichanl-YOUR_KEY

# 127.0.0.1:20128 üzerinde çalışıyor
curl http://127.0.0.1:20128/v1/messages \
  -H "x-api-key: sk-unichanl-YOUR_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{"model":"claude-sonnet-4","max_tokens":256,"messages":[{"role":"user","content":"Merhaba"}]}'

Claude Code için env değişkenleri

# Claude Code / Cursor / Codex ortak env
export ANTHROPIC_BASE_URL=http://127.0.0.1:20128
export ANTHROPIC_API_KEY=sk-unichanl-YOUR_KEY

# OpenAI uyumlu araçlar için
export OPENAI_BASE_URL=http://127.0.0.1:20128/v1
export OPENAI_API_KEY=sk-unichanl-YOUR_KEY

Somut kullanım senaryoları

Senaryo 1: Freelancer, aylık 150$ Claude Sonnet

OpenRouter'da ~157.5$ öderken Unichanl'da ~150$ ödersiniz. Yıllık ~90$ tasarruf. Ayrıca Anthropic rate limit'e girdiğinde işiniz durmaz — gateway otomatik olarak ikinci anahtara döner.

Senaryo 2: Ajans, 5 kişilik ekip

Beş geliştirici tek gateway key'i kullanır. Tüketim dashboard'dan kişi bazlı görünür. Şirket faturası TL olarak KDV'li düzenlenir.

Senaryo 3: Kurumsal KVKK gereksinimi

Hukuk ekibi US TOS'lu bir proxy'yi onaylamıyor. Unichanl'ın Türkiye'de kayıtlı KVKK aydınlatma metni sayesinde iç denetim geçilir; istekler kurumsal ağdan doğrudan provider'a gider.

Ne zaman OpenRouter kalmak mantıklı?

Eğer 300+ modelin (Nous, Qwen, deneysel Mistral fine-tune'ları) tek yerden erişimi kritikse OpenRouter kataloğu benzersizdir. Bu durumda Unichanl'ı ana gateway olarak koyup OpenRouter'ı bir upstream olarak eklemek en iyi hibrit çözümdür.

Migrasyon adımları

  1. Unichanl'a kayıt olun ve 5$ yükleyin.
  2. Dashboard'dan gateway key'i alın.
  3. OpenRouter env değişkenlerinizi Unichanl'ınkilerle değiştirin — OPENAI_BASE_URL ve ANTHROPIC_BASE_URL.
  4. Mevcut Anthropic/OpenAI/Google anahtarlarınızı Unichanl dashboard'ına ekleyin (opsiyonel — BYOK modu).
  5. Failover ve rate-limit havuzlaması otomatik devreye girer.

Sık sorulan sorular

OpenRouter'daki bakiyemi Unichanl'a taşıyabilir miyim?

Doğrudan transfer yok; her iki platform da bağımsız cüzdanlara sahiptir. Unichanl'a 5$ ile başlayıp OpenRouter bakiyenizi bitene kadar kullanabilirsiniz.

Unichanl'da hangi provider'lar destekleniyor?

Anthropic (direkt), OpenAI, Google Gemini, AWS Bedrock, Google Vertex ve upstream olarak OpenRouter.

Gateway kapalıysa ne olur?

Gateway sadece localhost'ta çalışan ince bir process'tir. Bilgisayar açık olduğu sürece pm2 veya sistem servisi olarak arka planda kalır.
