Claude Code Router: Unichanl Kurulumu

Güncelleme: 16 Eylül 2026 · 6 dk okuma
TL;DR: Claude Code'u Unichanl üzerinden çalıştırmak için tek bir ANTHROPIC_BASE_URL=http://127.0.0.1:20128 ayarı ve gateway key yeterlidir. Unichanl birden fazla Anthropic anahtarını havuzlar, rate limit'e girdiğinizde otomatik failover yapar, provider outage sırasında istekleri Bedrock/Vertex'e yönlendirir. Windows, macOS ve Linux'ta 2 dakikada kurulur.

Neden Claude Code + Unichanl?

Claude Code, Anthropic API'ye direkt konuşan bir CLI'dır. Uzun kodlama seanslarında en sık karşılaşılan problem tek anahtarın rate limit'e girmesi ve session'ın kesilmesidir. Unichanl router olarak devreye girdiğinde:

  • 2+ Anthropic anahtarını havuzlar, biri limit'e girerse diğeri devralır.
  • Anthropic direkt outage yaşarsa aynı Sonnet ailesini AWS Bedrock veya Google Vertex üzerinden servis eder.
  • Prompt/response içeriğini loglamaz — sadece metadata (token, latency).
  • Kullandıkça öde, marj yok — 5$ minimum topup.

Gereksinimler

  • Node.js 20+ (Claude Code için zaten gerekli).
  • Unichanl hesabı ve gateway key (fiyatlandırma sayfasından 5$ ile).
  • En az bir provider anahtarı (Anthropic önerilir; opsiyonel olarak OpenAI/Google/Bedrock).

Adım 1: Unichanl'ı yükle

npm install -g unichanl
unichanl --version

Adım 2: Gateway'i başlat

unichanl start --key sk-unichanl-YOUR_KEY

# Çıktı:
# [unichanl] gateway listening on 127.0.0.1:20128
# [unichanl] upstreams: anthropic-direct, bedrock, vertex
# [unichanl] routing mode: failover

Adım 3: Claude Code env değişkenlerini ayarla

macOS / Linux

# ~/.zshrc veya ~/.bashrc
export ANTHROPIC_BASE_URL=http://127.0.0.1:20128
export ANTHROPIC_API_KEY=sk-unichanl-YOUR_KEY

# Değişiklikleri yükle
source ~/.zshrc

Windows (PowerShell)

[Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "http://127.0.0.1:20128", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-unichanl-YOUR_KEY", "User")

# Yeni PowerShell penceresi açın

Adım 4: Doğrulama

# Claude Code'un gateway'e gittiğini doğrula
claude "merhaba, hangi model ile konuşuyorum?"

# Unichanl loglarını izle
unichanl logs --follow

Adım 5: Failover'ı test et

Dashboard'a girip primary anahtarı geçici olarak devre dışı bırakın. Claude Code oturumunuz kesilmez — istek ikinci anahtara veya Bedrock upstream'ine düşer. Unichanl logunda şu satır görünür:

[unichanl] anthropic-primary rate_limit → failover to bedrock-us-east
[unichanl] latency +42ms, request succeeded

Somut kullanım senaryosu

Cuma akşamı büyük bir refactor seansı. 3 saat kesintisiz Claude Code kullanıyorsunuz. 1. saatte Anthropic direkt anahtar Tier-2 limit'e giriyor — Unichanl otomatik olarak Bedrock'a düşüyor, siz farkında bile değilsiniz. 2. saatte Bedrock'ta us-east-1 kısa süreli sorun yaşıyor — Vertex EU üzerinden aynı Sonnet 4 servis ediliyor. Session hiç kesilmiyor. Toplam ek gecikme: ~80ms.

Sorun giderme

"Connection refused" hatası

Gateway çalışmıyor. unichanl status ile kontrol edin ve gerekirse unichanl start ile yeniden başlatın.

Claude Code hâlâ direkt Anthropic'e gidiyor

Env değişkenleri yüklenmemiş olabilir. Yeni bir terminal penceresi açın ve echo $ANTHROPIC_BASE_URL ile doğrulayın.

"Invalid API key"

Gateway key ile Anthropic key'i karışmış olabilir. ANTHROPIC_API_KEY, Anthropic'in sk-ant-... anahtarı değil, Unichanl'ın sk-unichanl-... anahtarı olmalı.

Kalıcı arka plan servisi

# pm2 ile
npm install -g pm2
pm2 start "unichanl start --key sk-unichanl-YOUR_KEY" --name unichanl
pm2 save
pm2 startup
